# XimaruTur — site vitrine (React + Vite)

    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera a pasta dist/

## Publicar na Vercel
Envie a pasta para um repositório no GitHub e importe em vercel.com/new.
A Vercel detecta o Vite sozinha (Build: `npm run build`, Output: `dist`).

## Editar conteúdo
- Atrativos e fotos: `src/data/atrativos.js` (importe a foto em `src/assets/passeios/` e preencha `imagem`)
- Modalidades: `src/data/modalidades.js`
- WhatsApp/Instagram: `src/data/contato.js`
- Estilos: `src/styles.css`
